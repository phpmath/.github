# Security policy

## Supported versions

Only the latest major version of each library receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately: open the repository that is affected, choose the **Security** tab and then **Report a vulnerability**. That sends the report to the maintainers only. Include the library, its version, and the steps to reproduce the problem.

You will get an answer as soon as possible. When the problem is fixed, a new release is published and the report is made public.
